# hn-research-mcp

hn-research-mcp is an open-source Hacker News research website plus remote MCP server, planned in Python with FastAPI and the official MCP Python SDK v2, with a strictly $0 budget.

Phase 0 documentation is recorded, with the remaining measurement gap and approval gates listed in the tracker. The repository contains design and validation documents only; the application, dependency manifest, and project tests have not been added.

- [Architecture contract](docs/architecture.md)
- [Technical validation](docs/technical-validation.md)
- [Deployment and request budget](docs/deployment.md)
- [Phase status](docs/phase-status.md)
- [Authoritative Phase 0 requirements](docs/phase-0-requirements.md)

Phase 1 remains blocked until the architecture decisions marked for approval are resolved. Phase 0 records historical and refreshed upstream measurements; its limits as samples are documented in `docs/deployment.md`.
